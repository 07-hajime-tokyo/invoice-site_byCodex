# 海外直取（FedEx）箱ID 出庫SOP

対象は海外直取のFedEx出庫だけです。eBay・ヤフオク・従来の箱なし出庫には使いません。

## 1. 箱シールを必要枚数だけ作る

1. 箱を先に用意する場合は「荷受け」上部、検品後に用意する場合は「出庫」→「海外直取：箱モード」を開きます。入荷0件・検品前でも発番できます。
2. 箱数（1〜20）を入力し、「箱を作る・○枚印刷」を押します。どちらの画面も同じ発番・印刷部品です。
3. ブラウザの印刷ダイアログに、指定枚数だけ表示されたことを確認して印刷します。
4. 太枠の箱IDシール（`B` + 6桁）を箱の外側へ貼ります。

使わなかった空箱は「開いたままの箱」に残ります。勝手には消えません。不要と確定した空箱だけ「破棄」を押します。破棄した箱IDは再利用されません。

## 2. 個体を箱へ入れて封をする

1. 共通スキャン欄で箱IDを読み取ります。
2. 箱へ入れる個体ラベル（英字7文字）を1点ずつ読み取ります。
3. 画面の点数・商品名・個体IDと現物を確認します。誤りは「取り消す」で外します。
4. 梱包後に「封をする」を押します。この時点で出庫履歴作成、個体の出庫済み化、在庫減算が行われます。追跡番号は不要です。

同じ箱IDを再読取しても箱は増えません。入庫済み／在庫以外の個体は理由付きで止まります。

## 3. FedExラベルを後日紐付ける

1. 「発送登録待ちの箱」に対象箱が出ていることを確認します。
2. 共通スキャン欄で箱IDを読み取ります。
3. 続けてFedExラベルの追跡番号を読み取ります。読めない場合はキーボード入力します。
4. 発送日を確認し、「追跡番号を紐付け」を押します。書き込み先はインボイスNoの取引先ごとに自動分割されます。取引先不明時は推測せずエラーで止まります。
5. 完了表示を確認します。スプレッドシート警告が出た場合はFedEx発送記録のエラーを確認します。

## 4. 封を解いて中身を入れ替える

1. `sealed` の箱は「封を解く」を押し、確認画面の戻る在庫数と全個体IDを現物と照合します。
2. 実行すると在庫数と個体状態が戻ります。出庫履歴は削除されず、取消内容が追記されます。
3. 開いた箱から個体を「取り消す」／別個体をスキャンし、もう一度「封をする」を押します。封をし直すたびに新しい出庫履歴が作られます。
4. `shipped` の箱は先に「追跡番号を解除」を押します。「Googleスプレッドシートの該当行も消える」確認後に解除され、箱が `sealed` に戻ります。その後、別操作の「封を解く」を実行します。

GASの行削除に失敗した場合、箱は `shipped` のままで変わりません。再確認してからやり直します。

## 5. 確認・例外

- 「個体IDから発送を追跡」に個体IDを入れると、個体 → 箱ID → 追跡番号を確認できます。
- 箱シールを個体の順番で、個体ラベルを箱の順番で読んでも、文字形式から正しい処理へ自動振り分けされます。
- 既に開いている箱へ「封を解く」が再送されても在庫は二重に戻りません。
- eBay・ヤフオク・箱を使わない出庫は、従来どおり下段の「出庫」を使います。

## 開発者向け

ブランチを切り替えたら、型検査やテストより先に `pnpm install` を実行します（`sharp` / `cheerio` を含む依存差分のため）。
