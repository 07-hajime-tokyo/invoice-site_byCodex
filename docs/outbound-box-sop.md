# 海外直取（FedEx）箱ID 出庫SOP

対象は海外直取のFedEx出庫だけです。eBay・ヤフオク・従来の箱なし出庫には使いません。

## 1. 箱シールを必要枚数だけ作る

1. 荷受けと動作確認を終え、出荷できる台数と必要な箱数を確定します。
2. 「出庫」→「海外直取：箱モード」で箱数（1〜20）を入力し、「箱を作る・○枚印刷」を押します。
3. ブラウザの印刷ダイアログに、指定枚数だけ表示されたことを確認して印刷します。
4. 太枠の箱IDシール（`B` + 6桁）を箱の外側へ貼ります。

使わなかった空箱は「開いたままの箱」に残ります。勝手には消えません。不要と確定した空箱だけ「破棄」を押します。破棄した箱IDは再利用されません。

## 2. 個体を箱へ入れて封をする

1. 共通スキャン欄で箱IDを読み取ります。
2. 箱へ入れる個体ラベル（英字7文字）を1点ずつ読み取ります。
3. 画面の点数・商品名・個体IDと現物を確認します。誤りは「取り消す」で外します。
4. 梱包後に「封をする」を押します。この時点で出庫履歴作成、個体の出庫済み化、在庫減算が行われます。追跡番号は不要です。

同じ箱IDを再読取しても箱は増えません。入庫済み／在庫以外の個体は理由付きで止まります。

## 3. FedExラベルを後日紐付ける

1. 「発送登録待ちの箱」に対象箱が出ていることを確認します。
2. 共通スキャン欄で箱IDを読み取ります。
3. 続けてFedExラベルの追跡番号を読み取ります。読めない場合はキーボード入力します。
4. 書き込み先シートと発送日を確認し、「追跡番号を紐付け」を押します。
5. 完了表示を確認します。スプレッドシート警告が出た場合はFedEx発送記録のエラーを確認します。

## 4. 確認・例外

- 「個体IDから発送を追跡」に個体IDを入れると、個体 → 箱ID → 追跡番号を確認できます。
- 箱シールを個体の順番で、個体ラベルを箱の順番で読んでも、文字形式から正しい処理へ自動振り分けされます。
- 箱を封じた後は中身を変更しません。変更が必要な場合は管理者へ連絡します。
- eBay・ヤフオク・箱を使わない出庫は、従来どおり下段の「出庫」を使います。
